## 📞 SOPORTE post-ENTREGA

### Para cambiar colores
Editar `src/index.css` sección `:root`

### Para agregar productos
1. Crear SVG en `public/images/`
2. Agregar objeto en `src/data/products.js`
3. Recompilar: `npm run build`

### Para personalizar texto
Buscar en `/src/pages/` y `/src/App.jsx`

### Para cambiar categorías
Editar `src/data/products.js` y actualizar referencias
